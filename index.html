Normalmente no hay prioridad aquí, salvo que algo se dispare o cambie el estado.

Después de limpieza, pasa el turno al oponente.

Nota: "Prioridad" indica cuándo los jugadores pueden lanzar hechizos o activar habilidades.
SBA = State Based Actions (acciones basadas en estado) el juego revisa automáticamente si hay algun cambio(por ejemplo, si un permanente tiene 0 de resistencia, se manda al cementerio).
Triggers = Saltan habilidades disparadas por un evento.
